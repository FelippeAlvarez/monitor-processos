Pesquisar no DJEN — pesquisa avulsa por OAB, número do processo, nome da parte e período (não grava nada)

Os filtros preenchidos valem juntos (E). Informe ao menos um entre OAB, número do processo e nome da parte. Período máximo de 366 dias; consultas muito amplas podem ser cortadas (o programa avisa). O resultado vem direto do DJEN e não é guardado: para acompanhar um processo, use “Cadastrar no monitor”. A busca por nome traz só o que o DJEN publicou com aquele nome. A pesquisa fica registrada no log de auditoria (quem, filtros e período).

Filtros de pesquisa no DJEN

Cadastre quantos filtros quiser: OAB, CPF/CNPJ ou trecho de texto. O programa avisa de publicações novas em processos que você ainda não cadastrou (os já cadastrados são acompanhados na aba Publicações). Ao cadastrar, valem só as publicações dos últimos 2 dias em diante; nada do histórico antigo é buscado nem guardado.

CPF/CNPJ e texto são buscados dentro do texto das publicações: só aparecem as que citam o termo (despachos curtos costumam trazer só o nome da parte). Pode perder publicações; use como alerta adicional.

Importar de planilha (Excel .xlsx, .csv, .txt ou relatório em página web)

Procura números CNJ em qualquer célula. Se houver cabeçalho com colunas “Cliente”, “Pasta” ou “Apelido”, elas acompanham os processos. Mostra uma prévia antes de cadastrar; processos já existentes são ignorados. Em lotes grandes, a primeira consulta de cada processo acontece aos poucos, pela varredura diária. Por padrão, os importados ficam só no cadastro (sem consulta diária); depois você marca os que quer monitorar. Arquivo .xls antigo: abra no Excel e salve como .xlsx.

Desmarcado, o processo fica só no cadastro: as publicações dele chegam pelo filtro de OAB, e o programa confere no DJEN, de tempos em tempos, se a sua OAB aparece nele (se não aparecer e houver publicação recente, ele entra sozinho no monitoramento e você é avisado).

O dígito verificador é conferido. Na primeira consulta, o histórico existente vira base de comparação: só movimentações posteriores geram alerta.

QuandoQuemAçãoDetalheIP

O CNJ pode trocar a chave a qualquer momento. A atual fica em datajud-wiki.cnj.jus.br/api-publica/acesso — se as consultas passarem a dar erro 401/403, atualize aqui.

Cada processo é consultado pelo número no servidor comunicaapi.pje.jus.br. Desmarque para usar somente o DataJud.

Cada processo ativo é consultado uma vez por dia, em blocos, começando na hora definida abaixo e continuando até consultar todos. Os mais antigos e os nunca consultados vão primeiro. Processos arquivados não são consultados.

O programa confere no DJEN os processos que NÃO estão em monitoramento diário. Se houver publicação recente e nenhuma citar a OAB cadastrada nos filtros, o processo entra sozinho no monitoramento (motivo “sem OAB”). Quando a OAB passar a aparecer numa publicação desse processo, ele sai sozinho (se você o marcou à mão, só aparece um aviso). Processos que você tirou do monitoramento à mão nunca são incluídos pela automação. Só funciona se houver ao menos um filtro do tipo OAB na aba Filtros.

Cálculo de prazo

Só são considerados os feriados nacionais (Lei 662/1949, Lei 6.802/1980 e Lei 14.759/2023). Feriados estaduais, municipais, Carnaval, Semana Santa, Corpus Christi e suspensões por ato do tribunal não entram sozinhos: cadastre aqui os que quiser considerar (isso pode alongar o prazo calculado).

Gmail: use uma “senha de app” criada só para esta finalidade, nunca a senha da conta. A senha fica gravada em texto simples no arquivo config.json da pasta de dados do servidor (não vai para o backup nem para o GitHub).

Janela do programa

O painel abre numa janela própria, sem barra de endereço (usa o Chrome, ou o Edge se não houver Chrome; nada é instalado). Se desmarcar, abre no navegador padrão. A mudança vale na próxima vez que o Monitor for iniciado. Fechar a janela não encerra o Monitor: para encerrar, feche a janela preta.

Resumo diário da agenda por e-mail

Usa o servidor de e-mail acima (e a chave “Enviar alerta por e-mail” precisa estar ligada). Cada responsável recebe os eventos dele; os destinatários gerais recebem tudo (ou só os eventos sem responsável, se você desmarcar a opção). Lembretes seguem o que foi escolhido em cada evento; vencidos em aberto são lembrados todo dia. O envio só acontece com o computador ligado e o Monitor aberto; se estava desligado, o aviso sai ao ligar.

Diagnóstico do DJEN (administrador)

Consulta o DJEN agora, para um processo, e mostra o texto exatamente como a API devolveu, junto com o que o programa guardaria. Não grava nada. Serve para conferir como as publicações chegam (por exemplo, repetidas). O resultado contém o texto das publicações: use só para conferência interna.
